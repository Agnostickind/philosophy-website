# The Great Library of Philosophy

## Project

The Great Library of Philosophy is an educational digital library exploring
more than 2,500 years of philosophy across civilizations, historical periods,
thinkers, philosophical branches, schools, books, literature, and major ideas.

The website is built as a static website and is hosted using GitHub Pages.

## Website Structure

The main areas of the website include:

- History — the historical development of philosophy across civilizations and periods.
- Thinkers — individual philosophers and major intellectual figures.
- Branches — major fields of philosophical inquiry.
- Schools — philosophical schools, movements, and traditions.
- Books — influential philosophical works and texts.
- Literature — philosophical literature and related writings.
- Blog — articles and discussions about philosophy.

## Content Principles

When modifying or creating content:

- Preserve philosophical and historical accuracy.
- Do not invent quotations, dates, works, events, or biographical facts.
- Distinguish historical facts from philosophical interpretation.
- Preserve the historical context of philosophical ideas.
- Avoid unnecessary repetition or filler.
- Use clear, informative, educational language.
- Preserve existing meaningful content unless a change is explicitly requested.

## HTML and Accessibility

When modifying pages:

- Preserve valid semantic HTML.
- Maintain a logical heading hierarchy.
- Use descriptive headings.
- Use descriptive image alt text.
- Preserve meaningful internal links.
- Do not remove navigation or important content without a clear reason.
- Keep essential content accessible without JavaScript where practical.
- Maintain responsive behavior across desktop and mobile layouts.

## SEO

Important pages should maintain:

- A descriptive and unique title.
- A useful meta description.
- A canonical URL.
- Appropriate robots directives.
- Open Graph metadata.
- Twitter metadata where appropriate.
- Appropriate JSON-LD structured data.
- A clear H1 heading.
- Logical H2 and H3 headings.
- Descriptive image alt attributes.
- Relevant internal links.

SEO changes should remain consistent with the actual content of the page.

## Technical Structure

The website primarily uses:

- HTML
- CSS
- JavaScript
- Images
- Video
- GitHub Pages

Keep page-specific styling and scripts separated from global site styles where practical.

Avoid introducing unnecessary dependencies for functionality that can be achieved with existing HTML, CSS, or JavaScript.

## Verification

After making significant changes:

1. Check the affected HTML for structural errors.
2. Verify internal links.
3. Verify canonical URLs.
4. Check responsive behavior.
5. Check that images and other assets load correctly.
6. Ensure existing navigation continues to work.
7. Verify that the page remains accessible to search engines and automated agents.
