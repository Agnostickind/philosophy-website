# The Great Library of Philosophy

The Great Library of Philosophy is an online philosophy reference library exploring more than 2,500 years of philosophical thought.

The project brings together philosophical history, major thinkers, branches of philosophy, schools and traditions, and important philosophical works in one structured and accessible resource.

## About the Project

The Great Library of Philosophy is a static web project built to make philosophical knowledge easier to explore through interconnected pages, chronological history, philosophical branches, schools, thinkers, and major works.

The website covers traditions ranging from Ancient Greek, Indian, Chinese, Persian, Islamic, African, and Egyptian philosophy to Medieval, Renaissance, Enlightenment, Modern, and Contemporary thought.
